# Paper Workspace

The supplied proceedings proposal uses this compact structure: title and affiliations; abstract and index terms; introduction with hypotheses, goals, significance, and validation protocol; literature review; methods; results tables; conclusion; limitations; ethical considerations; and references.

When editable proceedings sources are available, keep them here and use `references/bibliography.bib`. Preserve the mentor proposal's core comparisons: CoT baseline vs frozen HRM vs adapted HRM, clean vs noisy retrieval, and quality vs efficiency.

Replace placeholders only with results traceable to `results/summary.csv` and immutable raw runs. Report sample sizes, seeds, confidence intervals, significance tests, effect sizes where applicable, failures, exclusions, compute, limitations, and all material deviations. Do not overstate causality, hide negative results, or change the stated hypothesis to fit observed outcomes.

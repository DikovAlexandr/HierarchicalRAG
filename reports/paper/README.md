# Paper Workspace

The supplied proceedings proposal uses this compact structure: title and affiliations; abstract and index terms; introduction with hypotheses, goals, significance, and validation protocol; literature review; methods; results tables; conclusion; limitations; ethical considerations; and references.

When editable proceedings sources are available, keep them here and use `references/bibliography.bib`. Planned result tables should preserve the proposal's three core comparisons: CoT baseline vs frozen HRM vs adapted HRM, clean vs noisy retrieval, and quality vs efficiency. Replace placeholders only with results traceable to `results/summary.csv`.

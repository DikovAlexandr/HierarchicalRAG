# Reports

Create `figures/` and `tables/` only when verified results exist. Keep proceedings sources and the article outline under `paper/`. Add final presentation materials only when they are derived from the same reviewed results.

Every number and comparison must reference an experiment ID, resolved configuration, raw output, and statistical analysis. Report uncertainty, effect magnitude, negative results, failed runs, exclusions, resource use, and limitations. Do not select only favorable datasets, metrics, seeds, or examples, and do not turn exploratory observations into confirmatory claims without a new predefined experiment.

Keep claims aligned with the mentor-approved goal and hypotheses in `docs/project.md`. Any deviation must be motivated in `docs/decisions.md`. Keep narrative claims synchronized with `results/summary.csv`.
